# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, and assume good faith. Harassment,
discrimination, personal attacks and publishing others' private information are not
tolerated anywhere in the project: issues, pull requests, discussions or any other
channel.

**Enforcement.** Report unacceptable behaviour privately to the maintainers, using the
contact on the maintainer's GitHub profile or a private security advisory marked
"conduct". Reports are handled confidentially. Maintainers may remove content, or warn,
suspend or ban participants, following the Covenant's enforcement guidelines.
