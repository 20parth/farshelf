# Feature matrix

Legend for **Evidence** (about the reference product):

- **Verified (public claim)**: stated explicitly on featherdrive.app. We did
  not run the app, so nothing is verified by our own testing.
- **Partially verified**: stated, but some details are missing or unclear.
- **Inferred**: not stated. Deduced from related claims or platform
  constraints.
- **Unverified**: mentioned in passing, with too little information to
  describe.
- **Proposed**: our improvement. It doesn't exist in the reference.

**Farshelf status** is the state of this repository. Check it against
`README.md` and the test suite. ✅ shipped and tested · 🟡 partial ·
🗺️ roadmap.
