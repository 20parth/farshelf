# Getting help

1. Check [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) and the
   [known limitations](docs/research/KNOWN_LIMITATIONS.md).
2. Search existing issues.
3. Open a bug report using the template. Include your OS, Node version
   (`node --version`), the storage type, and the relevant lines from the Activity view.
   **Remove tokens, passwords and private file names first.**

Farshelf is a volunteer project with no paid support. There is no Farshelf account to
recover; your data lives in your storage and on your computer.
